프로젝트 정보 구현 기능과 데이터·보안 설계
PROJECT 01

주요 구현 내용

Riot API 연동

Riot ID로 LoL과 TFT의 프로필, 랭크, 최근 전적을 독립 조회합니다.

매치 데이터 분석

KDA, CS/분, 킬 관여율, 피해량과 시야 점수를 최근 15경기 기준으로 분석합니다.

자체 챔피언 티어

현재 패치·최근 28일 솔로랭크를 집계하고 표본 부족 시 등급을 보류합니다.

API 키 보안

Riot API 키와 Supabase Service Role 키를 서버 환경변수로만 관리합니다.

데이터 저장

Supabase에 매치와 참가자 데이터를 저장해 Vercel에서도 수집 결과를 유지합니다.

데모 모드

API 키나 DB 설정 없이도 주요 분석 기능을 확인할 수 있는 샘플 데이터를 제공합니다.

PROJECT 02

데이터 처리와 보안 설계

01

Riot API에서 매치 데이터를 수집하고, matchId를 기준으로 중복 저장을 방지합니다.

02

챔피언 티어는 수집 데이터로 계산한 자체 지표이며 Riot Games 공식 티어가 아닙니다.

03

API 키는 서버 환경변수로 관리하며 클라이언트에 노출하지 않습니다.

04

포트폴리오 검토를 위한 데모 서비스입니다.
